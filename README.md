# Люмен — лаунчер для Android

Нативный лаунчер (Kotlin + Jetpack Compose), повторяющий главный экран «Люмена»
из Teable и добавляющий собственные экраны.

## Что внутри

- **Главный экран** — часы 24 ч моноширинным шрифтом с цветными двоеточиями,
  дата, заряд батареи, погода (Open-Meteo + обратное геокодирование), аналоговые
  часы и процедурный фон: цвет зависит от времени суток и сезона, частицы
  медленно дрейфуют.
- **Мои приложения** — две независимые области:
  - «Приложения» — установленные приложения из `PackageManager` (поиск, сетка,
    долгое нажатие → сведения о приложении);
  - «Веб» — собственные веб-приложения из opencode/OpenChamber, которые
    открываются в отдельном WebView-контейнере (`WebAppActivity`) и не
    смешиваются с системным списком.
- **Настройки** — таймаут заставки, секунды на главном, перегенерация фона,
  выбор домашнего экрана, управление списком веб-приложений.
- **Заставка** — два режима:
  - внутри лаунчера: тот же главный экран без шапки и футера, полноэкранный
    режим, `KEEP_SCREEN_ON`, крестик для выхода, автозапуск через N минут
    бездействия;
  - системная `DreamService`: часы на процедурном фоне, включается в
    «Настройки → Экран → Заставка» (когда телефон на зарядке).

## Домашний экран

Приложение объявляет `CATEGORY_HOME`. Android не позволяет назначить лаунчер
тихо — пользователь выбирает его в системном диалоге. Кнопка выбора есть в
настройках лаунчера.

## Сборка

```bash
cd LumenLauncher
./gradlew assembleRelease
```

На ARM64-машине в `gradle.properties` уже прописан запуск `aapt2` через qemu-обёртку
(`android.aapt2FromMavenOverride`); в CI эта строка удаляется автоматически.

Ключ подписи по умолчанию — `../lumen-release.jks`, пароли можно переопределить
через `LUMEN_STORE_PASSWORD` / `LUMEN_KEY_PASSWORD` / `LUMEN_KEY_ALIAS` /
`LUMEN_STORE_FILE`. Секретов в репозитории нет.

Тесты: `gradle testReleaseUnitTest` (форматирование времени, границы периодов
суток, сезоны, коды погоды).

## Структура

```
app/src/main/java/ru/lumen/launcher/
  MainActivity.kt            — HOME-активность
  data/                      — PackageManager, DataStore, погода, веб-приложения
  ui/                        — главный экран, приложения, настройки, фон, заставка
  service/LumenDreamService  — системная заставка
  web/WebAppActivity         — контейнер веб-приложений
  util/Format.kt             — чистые функции времени/погоды (покрыты тестами)
```
