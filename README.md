# Люмен — лаунчер для Android

Нативный лаунчер (Kotlin + Jetpack Compose), повторяющий главный экран «Люмена»
из Teable и добавляющий собственные экраны.

## Что внутри

- **Главный экран** — часы 24 ч моноширинным шрифтом с цветными двоеточиями,
  дата, заряд батареи, погода (Open-Meteo + обратное геокодирование), аналоговые
  часы и процедурный фон: цвет зависит от времени суток и сезона, частицы
  медленно дрейфуют.
- **Мои приложения** — независимые области:
  - «Приложения» — установленные приложения из `PackageManager` (поиск, сетка,
    долгое нажатие → сведения о приложении);
  - «Веб» — собственные веб-приложения из opencode/OpenChamber, которые
    открываются в отдельном WebView-контейнере (`WebAppActivity`) и не
    смешиваются с системным списком;
  - по вкладке на каждое подключение (Teable, GitHub, OpenChamber) — живой
    список приложений сервиса с иконками и кнопкой «добавить в мои».
- **Вкладка «Отсюда»** — сборки, сделанные в opencode/OpenChamber:
  - список берётся из реестра `registry/apps.json` этого репозитория (адрес меняется
    в настройках), плюс автоматически подхватываются репозитории GitHub, у которых в
    релизе есть APK (нужен токен в подключении GitHub);
  - установленные показываются с системной иконкой и открываются сразу;
  - не установленные — с иконкой из реестра, ведут на страницу релиза, а кнопка
    «Скачать» приносит APK и передаёт его системному установщику.
- **Иконки везде**: у установленных приложений — системные, у веб-приложений и
  каталогов — манифест PWA или favicon (кэш в памяти и на диске), иначе плитка
  с буквой.
- **Персонаж ИИ** — отдельная вкладка:
  - четыре персонажа на выбор (Люмен, Циркон, Мята, Ноктюрн) — инопланетянин
    рисуется на Canvas, у каждого свой цвет, глаза, антенны и высота голоса;
  - режим **текст**: картинка персонажа, лента сообщений, озвучка ответа по тапу;
  - режим **голос**: только персонаж, рот двигается, пока он говорит, волны —
    пока слушает; речь и слух на встроенных средствах Android
    (`TextToSpeech` + `SpeechRecognizer`, бесплатно и без сети для распознавания
    через системный движок);
  - **навыки** подключаются в «Настройках → Персонаж → Навыки персонажа»:
    «Телефон» (реальные действия: будильник, уведомление, буфер обмена, запуск
    приложения, открытие ссылки, всплывающее сообщение), «Чакральная система»,
    «OpenCode», «Диагностика» плюс свои навыки текстом;
  - ответ-действие персонаж отдаёт строгой строкой JSON, лаунчер его выполняет.
- **Память персонажа** — персонаж помнит собеседника:
  - достаточно сказать «запомни, что меня зовут …» или просто рассказать о себе
    («я живу в Москве», «мой день рождения 04.11.1978») — факт сохраняется на
    телефоне и подмешивается в системную подсказку;
  - на прямые вопросы («как меня зовут?», «когда у меня день рождения?», «что ты
    помнишь обо мне?») персонаж отвечает из памяти сам — это работает даже без
    подключения ИИ и без сети;
  - «забудь моё имя» убирает факт; факт о том же (новое имя, новый город) заменяет
    прежний, а не копится;
  - диалог тоже переживает перезапуск лаунчера: история хранится по персонажам
    (последние 40 сообщений) и отключается переключателем «Помнить диалог»;
  - вся память видна и правится в «Настройках → Память персонажа»: список фактов,
    добавление вручную, удаление по одному и полная очистка.
- **Настройки** — таймаут заставки, секунды на главном, перегенерация фона,
  выбор домашнего экрана, персонаж с навыками, список веб-приложений и
  **подключения** к сервисам:
  - Teable — адрес + токен, тянет приложения App Builder со всех доступных баз;
  - GitHub — логин, публичный API без токена (лимит 60 запросов/час), показывает
    репозитории с GitHub Pages;
  - ИИ — OpenAI-совместимый адрес, ключ и модель, через него отвечает персонаж;
  - OpenChamber — адрес сервера + логин/пароль, показывает проекты и сессии.
  Подключение и веб-приложение можно изменить: коснитесь строки (или карандаша) —
  откроется то же окно с заполненными полями. У подключения «ИИ» есть кнопка
  **«Проверить связь»**: она делает настоящий запрос к модели и показывает ответ
  или точную причину сбоя (код HTTP и сообщение сервера). Адреса нормализуются:
  кавычки, пробелы и лишний слэш убираются, `https://` добавляется сам.
  Токены хранятся только на устройстве (DataStore приложения).
- **Заставка** — два режима:
  - внутри лаунчера: тот же главный экран без шапки и футера, полноэкранный
    режим, `KEEP_SCREEN_ON`, крестик для выхода, автозапуск через N минут
    бездействия;
  - системная `DreamService`: часы на процедурном фоне, включается в
    «Настройки → Экран → Заставка» (когда телефон на зарядке).

## Домашний экран

Приложение объявляет `CATEGORY_HOME`. Android не позволяет назначить лаунчер
тихо — пользователь выбирает его в системном диалоге. Кнопка выбора есть в
настройках лаунчера.

## Сборка

```bash
cd LumenLauncher
./gradlew assembleRelease
```

На ARM64-машине в `gradle.properties` уже прописан запуск `aapt2` через qemu-обёртку
(`android.aapt2FromMavenOverride`); в CI эта строка удаляется автоматически.

Ключ подписи по умолчанию — `../lumen-release.jks`, пароли можно переопределить
через `LUMEN_STORE_PASSWORD` / `LUMEN_KEY_PASSWORD` / `LUMEN_KEY_ALIAS` /
`LUMEN_STORE_FILE`. Секретов в репозитории нет.

Тесты: `gradle testReleaseUnitTest` (форматирование времени, границы периодов
суток, сезоны, коды погоды).

## Структура

```
app/src/main/java/ru/lumen/launcher/
  MainActivity.kt            — HOME-активность
  data/                      — PackageManager, DataStore, погода, веб-приложения
  ui/                        — главный экран, приложения, настройки, фон, заставка
  service/LumenDreamService  — системная заставка
  web/WebAppActivity         — контейнер веб-приложений
  util/Format.kt             — чистые функции времени/погоды (покрыты тестами)
```
